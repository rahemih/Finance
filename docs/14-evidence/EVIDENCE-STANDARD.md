# Evidence Standard

Evidence must be sufficient for an independent reviewer to reproduce or verify completion.

Depending on task type, record:

- Base/main SHA
- Branch/head SHA
- PR number
- Merge SHA
- CI workflow/run/job IDs
- Test reports and coverage
- Security scan result
- Performance benchmark
- Artifact hash
- Migration/schema version
- Dataset/feature/model/strategy version
- UI screenshots or visual-test evidence
- Demo/broker-simulator transaction IDs
- Human-gate evidence
- Lock acquire/release evidence
- Post-merge verification

Evidence must never contain secrets, private keys, passwords, tokens, or sensitive live-account data.
